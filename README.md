# bts119119
GitHub MCP 테스트 저장소

## 프로젝트 개요
bts119119는 GitHub MCP(Model Context Protocol)의 기능을 테스트하고 검증하기 위한 저장소입니다.
이 프로젝트를 통해 GitHub와의 통합 기능, 저장소 관리, 브랜치 작업 등을 체험할 수 있습니다.

## 주요 기능
- GitHub MCP 테스트
- 저장소 관리 기능 검증
- 브랜치 및 커밋 관리
- Pull Request 워크플로우 테스트

## 시작하기
```bash
git clone https://github.com/rethe08/bts119119.git
cd bts119119
```

## 브랜치 관리
- `master`: 메인 브랜치
- `feature3`: 기능 개발 브랜치
